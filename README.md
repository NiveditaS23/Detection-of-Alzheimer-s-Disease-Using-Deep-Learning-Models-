# Detection-of-Alzheimer-s-Disease-Using-Deep-Learning-Models-
Alzheimer’s Disease Detection Using Deep Learning

A deep learning-based system for the detection and classification of Alzheimer’s disease from brain MRI images. The project evaluates multiple deep learning and transformer-based architectures to identify the most effective approach for Alzheimer’s classification.

Project Overview

Alzheimer’s disease is a progressive neurological disorder that affects memory, thinking, and cognitive abilities. This project aims to develop an automated system that analyzes brain MRI images and classifies them into different stages of Alzheimer’s disease using deep learning.

The project implements and compares CNN, ResNet, DenseNet, Swin Transformer, and Vision Transformer (ViT) models for MRI-based image classification.

Models Used

CNN (Convolutional Neural Network) – Used as the baseline deep learning model for extracting spatial features from MRI images.


ResNet – Uses residual connections to enable deeper networks and improve feature extraction.


DenseNet – Uses densely connected layers to promote feature reuse and efficient gradient flow.


Swin Transformer – A hierarchical transformer architecture that captures both local and global image features.


Vision Transformer (ViT) – Applies transformer architecture directly to image patches to learn global relationships within MRI images.
